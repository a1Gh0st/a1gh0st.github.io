### Overview

This write-up documents my completion of the TryHackMe Pre-Security learning path and serves as a reference guide as I develop my cybersecurity skills.

The report combines notes from guided lessons and practice exercises with additional explanations, technical examples, key terminology, and review questions. My goal is to show what I studied, strengthen my understanding of the fundamentals, and establish a foundation for penetration testing and future AI security work.

### Seven Modules Covered

1. **Introduction to Cyber Security:** Offensive versus defensive security, roles, and ethical scope.
2. **Computer Fundamentals:** Hardware, client-server systems, virtualization, and cloud computing.
3. **Operating Systems Basics:** Windows, Linux, command lines, permissions, and operating system security.
4. **Software Basics:** Data representation, encoding, Python, JavaScript, and SQL.
5. **Network Fundamentals:** Local networks, OSI layers, packets, frames, and network communication.
6. **How the Web Works:** DNS, HTTP, web architecture, and secure input handling.
7. **Attacks and Defenses:** CIA triad, cryptography, reconnaissance, enumeration, and defensive controls.
