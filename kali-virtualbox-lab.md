## Project Overview

The **Kali Linux VirtualBox Lab** is an ongoing hands-on cybersecurity project built around running Kali Linux as a virtual machine in Oracle VirtualBox. The environment supports practical Linux learning, network troubleshooting, and ethical-hacking exercises conducted against owned or explicitly authorized systems.

**Current status:** In Progress. VirtualBox and Kali Linux are installed, and the Kali graphical desktop has been confirmed running. Other configuration and testing steps will be documented only when verified.

## Project Description

This project began with the virtual lab setup from the **Complete Ethical Hacking Bootcamp** on Udemy. Virtual machines provide a controlled place to practice the course's concepts without testing real-world networks or systems without permission.

The lab will develop over time through installation notes, system configuration, networking experiments, troubleshooting, and exercises. Rather than accumulating everything on one page, **each dated thread will document a specific work session**, including what was done, the evidence available, any problems encountered, and what remains to be tested.

This virtual lab is separate from the [Linux Home Lab](/projects/linux-home-lab/), which covers rebuilding a physical computer.
